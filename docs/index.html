Campaign tracking and claims/disputes linked to clients.

Run the full interactive demo

This site is the project homepage. The live app runs on your machine with Node.js:

git clone https://github.com/Tstowe0/DALKOCRM.git
cd DALKOCRM/Main
npm install
npm run db:seed
npm run dev

Then open http://localhost:3000 — you'll land on the Leads board with sample data.
